# UI组件开发 (UI Components)

## 概述

开发工时追踪器的UI组件，实现米家风格的用户界面。

## 目标

- 实现打卡按钮组件
- 实现进度卡片组件
- 实现日历网格组件
- 实现热力图组件
- 实现设置页面

## 非目标

- 复杂动画效果
- 自定义主题系统
- 响应式布局

## 用户价值

提供美观、易用的用户界面，提升使用体验。

## 组件清单

### 1. 打卡组件
- ClockOutButton - 打卡按钮
- LeaveToggle - 请假切换

### 2. 统计组件
- ProgressCard - 进度卡片

### 3. 日历组件
- CalendarGrid - 日历网格
- Heatmap - 热力图
- EditRecordSheet - 编辑弹窗

### 4. 通用组件
- TabBar - 底部导航
- Toast - 提示消息

## 设计规范

- 风格：米家风格，简洁清爽
- 间距：8px基准
- 圆角：12px
- 阴影：轻微阴影
