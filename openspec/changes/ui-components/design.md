## 打卡按钮组件 (ClockOutButton)

### 设计规格

```
┌─────────────────────────────────────────┐
│                                         │
│         ┌─────────────────────┐         │
│         │                     │         │
│         │    180 × 180 px    │         │
│         │                     │         │
│         │    ┌───────────┐   │         │
│         │    │  下班打卡  │   │         │
│         │    │           │   │         │
│         │    │ 点击记录   │   │         │
│         │    │ 下班时间   │   │         │
│         │    └───────────┘   │         │
│         │                     │         │
│         └─────────────────────┘         │
│                                         │
│         圆角: 90px (圆形)               │
│         背景: #34C759 (绿色)            │
│         文字: 白色                      │
│                                         │
└─────────────────────────────────────────┘
```

### 状态变化

| 状态 | 背景色 | 文字 |
|------|--------|------|
| 默认 | #34C759 | 下班打卡 |
| 已打卡 | #8E8E93 | 已打卡 |

### Props接口

```typescript
interface ClockOutButtonProps {
  isClocked: boolean
  onClockOut: () => void
  onUndo: () => void
}
```

## 进度卡片组件 (ProgressCard)

### 设计规格

```
┌─────────────────────────────────────────┐
│  本周进度                        32.5h/52.5h │
│  ┌─────────────────────────────────────┐│
│  │████████████████████░░░░░░░░░░░░░░░░││
│  └─────────────────────────────────────┘│
│  缺口 20h · 请假 1天                    │
└─────────────────────────────────────────┘
```

### 进度条颜色

| 状态 | 颜色 |
|------|------|
| 达标 (≥100%) | #34C759 (绿色) |
| 未达标 (<100%) | #FF9F0A (橙色) |

### Props接口

```typescript
interface ProgressCardProps {
  title: string
  currentHours: number
  targetHours: number
  gap: number
  leaveDays: number
  overtimeDaysNeeded?: number
}
```

## 日历网格组件 (CalendarGrid)

### 设计规格

```
┌─────────────────────────────────────────┐
│     一   二   三   四   五   六   日     │
│  ┌────┬────┬────┬────┬────┬────┬────┐  │
│  │    │    │    │  1 │  2 │  3 │  4 │  │
│  │    │    │    │    │    │    │    │  │
│  ├────┼────┼────┼────┼────┼────┼────┤  │

```

│                                         │
│  2024-01-15                     ✕ 关闭  │

│  下班时间: [22:30    ]                  │
│                                         │
│  ┌─────────────────────────────────────┐│
│  │              保存                   ││
│  └─────────────────────────────────────┘│
│                                         │
│  ┌─────────────────────────────────────┐│

│                                         │
