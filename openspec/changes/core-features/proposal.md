# 核心功能实现 (Core Features)

## 概述

实现工时追踪器的核心业务逻辑，包括打卡、统计和数据管理功能。

## 目标

- 实现下班打卡功能
- 实现工时统计计算
- 实现数据导入导出
- 实现配置管理

## 非目标

- UI美化
- 动画效果
- 通知功能

## 用户价值

提供完整的工时追踪能力，满足日常考勤记录需求。

## 功能清单

### 1. 下班打卡
- 记录下班时间
- 自动计算工时
- 支持撤销打卡
- 支持请假标记

### 2. 工时统计
- 本周进度计算
- 本月进度计算
- 缺口和加班天数

### 3. 数据管理
- JSON格式导出
- 从文件导入
- 数据覆盖策略

### 4. 配置管理
- 应出勤天数设置
- 周类型切换

## 技术要点

- Zustand actions实现业务逻辑
- dayjs处理日期计算
- 平台适配的存储方案
