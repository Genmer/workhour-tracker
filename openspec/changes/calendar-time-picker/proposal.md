# 日历历史数据补充功能 (Calendar History Data Fill)

## 背景

用户在月中开始使用应用时，前半月的考勤数据为空，导致：
- 热力图显示不完整
- 月度统计不准确
- 无法回顾历史考勤情况

## 用户故事

作为用户，我想要在日历上补充历史考勤数据，以便完整记录本月工时。

## 功能需求

### 1. 时间选择器

点击日历上的任意日期，弹出增强版时间选择器：

#### 快捷选择区
- 预设常用下班时间：18:00、21:30、22:30
- 一键选择，快速录入

#### 详细选择区
- 小时选择：00-23
- 分钟选择：00-59（间隔5分钟）
- 滑动选择或滚轮选择

### 2. 交互流程

```
用户点击日期
     │
     ▼
┌─────────────────────────────┐
│      时间选择器弹窗         │
│  ┌───────────────────────┐  │
│  │    快捷选择           │  │
│  │  [18:00] [21:30] [22:30]│  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │    详细选择           │  │
│  │    [小时] : [分钟]    │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │    [保存] [取消]      │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │    [标记请假]         │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
     │
     ▼
保存到本地存储
```

### 3. 数据验证

- 不能选择未来时间
- 不能选择早于上班时间（09:00）
- 已有数据时显示确认覆盖提示

## 非目标

- 批量导入历史数据
- 从其他应用导入
- 自动推算下班时间

## 用户价值

- 补充历史数据，使统计更准确
- 灵活的时间选择方式
- 快捷选择提升录入效率

## 成功指标

- [ ] 点击日期能打开时间选择器
- [ ] 快捷选择能正确保存时间
- [ ] 详细选择能正确保存时间
- [ ] 数据能正确持久化
- [ ] 日历能正确显示补充的数据
