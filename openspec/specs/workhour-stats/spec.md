# 工时统计功能 (WorkHour Stats)

## 概述

统计和展示用户的工作时间，包括本周和本月的进度追踪。

## 用户故事

作为上班族，我想要了解本周/本月的工时进度，以便合理安排工作时间。

## 功能要求

### 本周进度卡

1. **显示内容**
   - 标题：「本周进度」
   - 数值：当前工时h / 目标工时h
   - 进度条（绿色=达标，橙色=未达标）
   - 统计：缺口 Xh、请假 X天（如有）

2. **计算逻辑**
   - 本周范围：周一到周日
   - 目标工时：根据周类型（大周52.5h / 小周63h）
   - 缺口 = 目标工时 - 实际工时

### 本月进度卡

1. **显示内容**
   - 标题：「本月进度」
   - 数值：当前工时h / 目标工时h
   - 进度条
   - 统计：缺口 Xh、请假 X天、需加班 X天（如有）

2. **计算逻辑**
   - 本月范围：当月1日到月末
   - 目标工时 = 应出勤天数 × 每日目标工时
   - 缺口 = 目标工时 - 实际工时
   - 需加班天数 = Math.ceil(缺口 / 每日目标工时)

### 底部提示

当本月有缺口时，显示橙色背景卡片：
> 「本月工时缺口 Xh，折合需加班 X 天」

### 数据模型

```typescript
interface WorkStats {
  totalHours: number       // 实际工时总和
  targetHours: number      // 目标工时总和
  gap: number              // 工时缺口（正=不足，负=溢出）
  leaveDays: number        // 请假天数
  overtimeDaysNeeded: number  // 需加班天数
}
```

### 周类型配置

| 周类型 | 工作天数 | 目标工时 |
|--------|----------|----------|
| 大周 | 5天 | 52.5h |
| 小周 | 6天 | 63h |

## 验收标准

- [ ] 本周进度计算正确
- [ ] 本月进度计算正确
- [ ] 进度条颜色正确显示
