# 日历视图功能 (Calendar View)

## 概述

提供月度日历视图，展示每日考勤状态，支持查看和编辑历史记录。

## 用户故事

作为上班族，我想要通过日历查看历史考勤记录，以便了解出勤情况。

## 功能要求

### 月份导航

- 居中显示：YYYY年M月
- 左右箭头切换月份

### 日历网格

1. **表头**
   - 显示：一 二 三 四 五 六 日

2. **日期格子**
   - 显示日期数字
   - 今日有绿色圆环标识
   - 未来日期灰色不可点击
   - 有记录时底部显示工时（颜色标识状态）：
     - 绿色 = 达标（≥10.5h）
     - 橙色 = 未达标（<10.5h）
     - 灰色 = 请假（显示「休」）

### 日期详情弹窗

点击日期弹出底部弹窗：

1. **标题**
   - 显示：YYYY-MM-DD

2. **已请假状态**
   - 提示：「当日已标记为请假」
   - 按钮：「取消请假」

3. **未请假状态**
   - 输入框：下班时间（HH:mm）
   - 按钮：「保存」
   - 按钮：「标记请假」

4. **底部信息**
   - 显示：当日工时 Xh

### 年度热力图

1. **月份标签**
   - 显示：1月 - 12月

2. **热力图方块**
   - 类似 GitHub 贡献图
   - 颜色梯度：
     - 无数据 → 浅灰
     - 浅绿 → 中绿 → 深绿 → 最深绿

3. **图例**
   - 显示：少 → 色块 → 多

### 每月出勤统计

- 标题：「每月出勤」
- 12个格子，每格显示：月份 + 出勤天数
