# 下班打卡功能 (Clock-Out)

## 概述

核心打卡功能，允许用户记录下班时间并自动计算当日工时。

## 用户故事

作为上班族，我想要快速记录下班时间，以便追踪每日工时是否达标。

## 功能要求

### 核心交互

1. **打卡按钮**
   - 大圆形按钮（180×180），绿色背景
   - 默认态显示：「下班打卡」+「点击记录下班时间」
   - 已打卡态显示：「已打卡」+「点击撤销」（灰色）

2. **打卡行为**
   - 点击后记录当前时间作为下班时间
   - 自动计算当日工时：下班时间 - 上班时间 - 午休时长
   - 显示打卡结果：下班时间 HH:mm · 工时 Xh

3. **撤销打卡**
   - 已打卡状态下再次点击可撤销
   - 撤销后删除当日打卡记录

4. **请假功能**
   - 圆形灰色按钮（44×44），标「休」字
   - 点击切换请假状态
   - 请假时工时记为0

### 数据模型

```typescript
interface WorkRecord {
  dateId: string           // 日期ID，格式 YYYY-MM-DD
  clockOutTime: string | null  // 下班时间，null=未打卡
  actualWorkHours: number  // 当日净工时（小时）
  isLeave: boolean         // 是否全天请假
}
```

### 工时计算规则

```
净工时 = 下班时间 - 上班时间 - 午休时长
```

- 上班时间：默认 09:00（可配置）
- 午休时长：默认 1.0 小时（可配置）
- 示例：22:30下班 → 22:30 - 09:00 - 1.0 = 12.5h
